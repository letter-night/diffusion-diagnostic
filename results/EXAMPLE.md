# Example results (dry-run stub)

These artifacts are committed as an **example** of what the pipeline produces. They were
generated by the **dry-run sampler**, which fabricates deliberately skewed completions
(including ~4% malformed metadata). **They validate the pipeline, not real model behavior** —
they are not evidence about any actual diffusion LM.

Generated with:

```bash
python -m src.run sample   --model dry_run --case all --variant all --n-prompts 24 --n-per-prompt 32
python -m src.run annotate --model dry_run --case all --variant all --judge
python -m src.run report   --model dry_run --case all --variant all
```

Tracked here:
- `report.md` — per-case/variant achieved-vs-target tables, TV/L1/L2/KL/entropy, bootstrap CIs, diversity
- `aggregate/` — `summary_table.csv` + per-(case×variant) JSON summaries
- `figures/` — target-vs-achieved bar charts + Case 1 gender×region heatmaps

Not tracked (bulky, regenerable): `raw/` (every prompt+completion) and `annotations/`
(per-completion parsed labels). Re-run the `sample` + `annotate` commands above to recreate them.

For real evidence, swap `--model dry_run` for `--model llada` on a >=24 GB GPU pod.
